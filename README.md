## 🚀 О проекте

**Mercy** — это современная, легковесная альтернатива Mechvibes, полностью переписанная на **Rust** с использованием нативного фреймворка **Dioxus**.

Оригинальный Mechvibes на Electron страдает от высокого потребления оперативной памяти (150–300+ МБ), задержек воспроизведения звука и рисков ложного срабатывания античитов из-за низкоуровневых глобальных хуков. **Mercy** полностью решает эти проблемы, обеспечивая бескомпромиссную отзывчивость и нулевое влияние на частоту кадров в играх.

## ✨ Ключевые преимущества

- **⚡ 0% влияния на FPS**: Прямой перехват через нативный **Windows Raw Input** без блокирующих хуков (`WH_KEYBOARD_LL`), что исключает лаги ввода и конфликты с античитами.
- **🛡️ 100% приватность и Zero Telemetry**: Из кодовой базы полностью вырезаны сторонние трекеры (Aptabase) и фоновые сетевые потоки. Никаких сетевых запросов при запуске и работе.
- **🪶 Минимальное потребление памяти**: Потребляет всего **25–40 МБ ОЗУ** вместо 200+ МБ у решений на базе Chromium/Electron.
- **🎧 Мгновенный отклик звука**: Звуковой движок работает на отдельном выделенном системном потоке с событийной моделью (`crossbeam`). Задержка воспроизведения составляет менее 5–10 мс.
- **🔊 32-голосная полифония**: Чистое звучание при быстрой печати без клиппинга, треска и заиканий.
- **🖱️ Звуки клавиатуры и мыши**: Независимая настройка громкости и выбор звуковых паков для клавиш и кнопок мыши.
- **📁 Поддержка всех звуковых паков**: Встроенная поддержка форматов V1 (классический Mechvibes) и современного V2, автоматическая конвертация и поддержка форматов WAV, OGG, MP3, FLAC.
- **🎛️ Удобное управление**: Быстрое отключение звука горячей клавишей `Ctrl+Alt+M`, сворачивание в системный трей, кастомизация оформления и логотипа.

## 🛠️ Сборка из исходников

### Требования
- [Rust toolchain](https://rustup.rs/) (версия 1.88 или новее)
- Windows SDK / Visual Studio C++ Build Tools (для Windows)

### Сборка
```bash
# Клонирование репозитория
git clone https://github.com/Arean-Max/Mechvibes-Mercy.git
cd Mechvibes-Mercy

# Проверка и компиляция релизного бинарника
cargo build --release
```

Готовый исполняемый файл будет находиться по пути:
```
target/release/mercy.exe
```

## 🎹 Добавление звуковых паков

Звуковые паки можно добавлять простым перетаскиванием папки в окно программы (Drag & Drop) или через меню:
1. Откройте **Settings** -> **Soundpacks** -> **Import Soundpack**.
2. Выберите папку со звуковым паком.
3. Программа автоматически распознает структуру и конвертирует классические паки при необходимости.

Пользовательские звуковые паки хранятся в:
- **Windows**: `%APPDATA%\Mercy\soundpacks` или рядом с исполняемым файлом в папке `soundpacks/`.
