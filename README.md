# Mercy

Легковесный симулятор звуков механической клавиатуры и мыши, написанный на Rust.

Форк [Mechvibes](https://github.com/hainguyents13/mechvibes-dx), переписанный с упором на минимальное потребление ресурсов, нулевые задержки звука и полное отсутствие телеметрии.

[English version](README.en.md)

## Особенности

* **Низкое потребление памяти** — ~25-40 МБ ОЗУ вместо 150-300+ МБ у оригинального Mechvibes на Electron.
* **Минимальная задержка звука** — аудио обрабатывается в отдельном системном потоке, отклик менее 10 мс даже при быстрой печати.
* **0% влияния на FPS** — ввод перехватывается через Windows Raw Input без блокирующих глобальных хуков (`WH_KEYBOARD_LL`), что исключает лаги и конфликты с античитами.
* **Звуки клавиатуры и мыши** — раздельная настройка громкости и звуковых паков для клавиш и кликов мыши.
* **32-голосная полифония** — одновременное воспроизведение звуков без щелчков и обрывов.
* **Полностью оффлайн (100% FOSS)** — вырезана вся аналитика, телеметрия и сторонние трекеры (Aptabase).
* **Поддержка любых паков** — читает звуковые паки Mechvibes (v1 и v2), поддерживает WAV, MP3, OGG, FLAC.
* **Горячие клавиши** — быстрое отключение звука по `Ctrl+Alt+M`, сворачивание в трей.

## Установка и запуск

Готовые сборки доступны на странице [Releases](https://github.com/Arean-Max/Mechvibes-Mercy/releases):

* Скачайте `Mercy-v0.8.3-windows-x64.zip`.
* Распакуйте архив в любую папку и запустите `mercy.exe`.

Все стандартные звуковые паки уже включены в архив в папке `soundpacks/`.

## Добавление звуковых паков

1. Перетащите папку со звуковым паком прямо в окно программы (Drag & Drop), либо откройте **Настройки -> Soundpacks -> Import Soundpack**.
2. Пользовательские паки хранятся в `%APPDATA%\Mechvibes\soundpacks` или в папке `soundpacks/` рядом с программой.

## Сборка из исходников

Для сборки потребуется [Rust](https://rustup.rs/) (1.88+):

```bash
git clone https://github.com/Arean-Max/Mechvibes-Mercy.git
cd Mechvibes-Mercy
cargo build --release
```

Исполняемый файл появится в `target/release/mercy.exe`.
